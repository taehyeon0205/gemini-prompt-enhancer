# 🪄 Gemini Prompt Enhancer (제미나이 프롬프트 마법사)

![Version](https://img.shields.io/badge/version-2.5-blue.svg)
![Chrome](https://img.shields.io/badge/Chrome-Extension-4285F4.svg?logo=googlechrome&logoColor=white)
![Gemini API](https://img.shields.io/badge/Gemini-API-8E75B2.svg)

**Gemini Prompt Enhancer**는 사용자의 모호하고 거친 입력을 구글 제미나이(Gemini)가 가장 잘 이해할 수 있는 **'최상급 프롬프트'**로 실시간 변환해 주는 크롬 확장 프로그램입니다. 

단순한 텍스트 치환을 넘어, **이전 대화의 맥락(Context)을 이해하고 스스로 추론**하는 엔터프라이즈급 아키텍처를 자랑합니다.

---

## ✨ 주요 기능 (Key Features)

### 🧠 1. 실시간 맥락 인지 (Context-Awareness)
* **슬라이딩 윈도우 알고리즘:** 화면에 있는 최근 대화 3개(최대 1,000자)를 실시간으로 스크래핑합니다.
* **대명사 완벽 추론:** "아까 말한 그거 다시 써줘"라고 입력해도, 이전 대화 맥락을 파악하여 정확한 고유명사로 치환합니다.
* **실시간 동기화 뱃지:** 제미나이 웹페이지의 DOM 변화를 감지하여(Mutation Observer), 현재 참조 중인 맥락의 개수를 플로팅 버튼(🧠 0~3)에 실시간으로 표시합니다.

### ✍️ 2. 인앱 편집기 및 완벽한 통제권 (In-app Editor)
* AI가 제안한 프롬프트를 전송하기 전, 팝업창 내부의 `<textarea>`에서 사용자가 직접 타이핑하여 2차 수정을 할 수 있습니다.
* [취소] 클릭 시 작성 중이던 텍스트 손실 없이 원래의 입력창으로 포커스가 부드럽게 복귀합니다.

### ⚙️ 3. GUI 설정 팝업 (Easy Configuration)
* 소스 코드 수정 없이, 확장 프로그램 아이콘을 클릭하여 **API Key**와 **AI 모델**(예: `gemini-2.5-flash`)을 직관적으로 변경할 수 있습니다.
* 설정값은 `chrome.storage.sync`를 통해 사용자의 구글 계정에 안전하게 클라우드 동기화됩니다.

### 🚨 4. 우아한 실패 및 스마트 쿨다운 (Graceful Degradation)
* **스마트 에러 파서:** 서버에서 발생한 HTTP 에러(400, 401, 404 등)를 분석하여 `🔑 API 키 오류`, `📝 프롬프트 형식 오류` 등 직관적인 UI 애니메이션으로 변환합니다.
* **429 Rate Limit 방어:** API 호출 한도 초과 시, 버튼이 즉시 **⏳ 60초 카운트다운 타이머**로 변신하여 사용자의 대기를 돕고 시스템 오작동을 방지합니다.

### 🛡️ 5. 보안 필터링 및 토큰 다이어트
* **PII 마스킹:** 이메일, 전화번호, 주민번호 등 민감한 개인정보가 API 서버로 전송되기 전 브라우저 단에서 `[보호됨]`으로 안전하게 마스킹 처리됩니다.
* **토큰 절약:** 무의미한 인사말이나 중복된 텍스트를 전처리 과정에서 삭제하여 API 토큰(비용)을 획기적으로 절약합니다.

## 🛠 설치 방법 (Installation)

현재 크롬 웹 스토어 심사 준비 중이며, 개발자 모드를 통해 즉시 설치할 수 있습니다.

1. 이 레포지토리를 Clone 하거나 `ZIP` 파일로 다운로드하여 압축을 풉니다.
2. 크롬 브라우저 주소창에 `chrome://extensions/`를 입력하여 접속합니다.
3. 우측 상단의 **[개발자 모드]** 토글을 켭니다.
4. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]**를 클릭하고, 다운로드한 폴더를 선택합니다.
5. 설치가 완료되면 브라우저 우측 상단 퍼즐(🧩) 아이콘을 눌러 확장 프로그램을 고정(📌)합니다.
6. 팝업창을 열어 본인의 **Gemini API Key**를 입력하고 저장합니다.

## 🚀 사용 가이드 (How to Use)

1. [Google Gemini](https://gemini.google.com/) 웹사이트에 접속합니다. (최초 설치 시 새로고침 `F5` 필수)
2. 하단 입력창에 머릿속에 떠오르는 모호한 지시사항을 대충 입력합니다. (예: *"이거 표 형태로 정리해 봐"*)
3. 엔터 대신 화면 우측 하단의 파란색 **`✨ 프롬프트 다듬기`** 플로팅 버튼을 클릭합니다.
4. 팝업창에서 AI가 다듬어준 고품질 프롬프트를 확인합니다.
5. 마음에 들면 **[적용하고 전송]**을 클릭하고, 수정하고 싶다면 텍스트 박스에서 직접 수정한 뒤 전송합니다.

## 🏗 시스템 아키텍처 (Architecture)

* **Pure Client-side:** 별도의 백엔드(Proxy) 서버 없이 오직 크롬 확장 프로그램 API만으로 동작하여 사용자의 데이터 프라이버시를 보장합니다.
* **Background Service Worker:** 확장 프로그램의 상태를 중앙에서 관리하고 외부 API 통신을 전담합니다.
* **Content Scripts:** 동적으로 제미나이 DOM에 접근하여 맥락을 추출하고 플로팅 UI를 렌더링합니다.
